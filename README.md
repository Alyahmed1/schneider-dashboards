# schneider-dashboards

Industrial monitoring dashboards in one repo. Each folder is a standalone Vite + React + TypeScript app.

| Folder | Dashboard |
|---|---|
| `aluminium` | Aluminium factory |
| `jotun-factory` | Jotun factory |
| `smart-port` | Smart port |
| `smart-airport` | Smart airport |
| `audio-technology-1` | Audio technology (1) |
| `audio-technology-2` | Audio technology (2) |

## Run one

```bash
cd smart-port
npm install
npm run dev
```

Every folder works on its own, so one dashboard never affects another.

## History

Each dashboard was merged in from its own repository with its full commit history. `aluminium` was added from a local folder, so its history starts here.
